## Nota de confiabilidade

As páginas da Meta podem mudar, redirecionar ou aplicar rate limit. Por isso:

- os documentos não congelam números mutáveis como verdade permanente;
- a versão concreta da Graph API será fixada;
- capacidades serão testadas com contas de teste;
- restrições oficiais prevalecerão sobre esta especificação;
- toda divergência será registrada antes de alterar o comportamento.
